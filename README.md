# 🧮 Calculadora em C

Calculadora simples feita na linguagem C. Permite realizar operações básicas diretamente no terminal: **soma, subtração, multiplicação e divisão**.

---

## 🔧 Tecnologias utilizadas

- Linguagem C
- Terminal (CLI)

---

## 🚀 Como compilar e executar


```bash
gcc calculadora.c -o calculadora
